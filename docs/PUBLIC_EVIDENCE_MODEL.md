# Public Evidence Model

The public repository intentionally contains only evidence that is safe to disclose.

## Evidence classes

- **Recorded** — administratively preserved; not independently validated.
- **Observed** — directly seen in a primary artifact, live state, or authoritative source.
- **Externally verified** — checked against a named authoritative source on the recorded date.
- **Reproduced** — repeated under the same bounded conditions.
- **Validated** — evidence supports the proposition and material alternatives were checked.
- **Remediated** — a corrective change was applied.
- **Retested** — the original validation was repeated after remediation.
- **Rejected** — evidence did not support the proposition.
- **Uncertain** — evidence is incomplete; no definitive claim is made.

## Publication boundary

The sanitized governance bootstrap is intentionally public and contains no operational approval. G4 governs any later publication/disclosure of lab findings or evidence beyond that bootstrap; it does not retroactively characterize creation of this public control repository.

Never publish secrets, real credentials, personal data, private conversation content, private infrastructure identifiers, or unnecessary exploit detail. Public evidence should prefer repository-native artifacts, authoritative public sources, synthetic lab data, and redacted/sanitized outputs.
