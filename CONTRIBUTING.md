# Contributing

Contributions must preserve the repository's authorization boundary and fail-closed governance model.

- Do not add real credentials, private keys, personal data, private infrastructure details, or third-party confidential information.
- Do not broaden scope through narrative text; only the canonical JSON state can define authority.
- Authority-changing pull requests must not modify the trusted guardian or transition checker in the same change.
- Evidence is append-only.
- Security claims must distinguish observed facts, external verification, inference, and unknowns.
- Material control changes require tests and review before merge.
