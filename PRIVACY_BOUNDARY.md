# Privacy boundary

This repository is PUBLIC. Treat every committed byte as permanently public and potentially mirrored, indexed, cached or archived.

Only sanitized governance, synthetic/local-lab material, public-source references, non-sensitive test code and deliberately publishable evidence may be committed.

## Never commit

- credentials, tokens, passwords, cookies, API keys, private keys or recovery codes;
- personal case/evidence data, medical/financial/benefits records or private correspondence;
- raw conversation/export archives;
- real private infrastructure identifiers, internal network details or sensitive system configuration;
- any third-party confidential or non-public data unless it is explicitly authorized for public disclosure; access or testing authorization alone is not publication consent;
- unredacted logs, screenshots or diagnostic bundles containing personal or infrastructure details.

Before committing, ask: would this still be safe if copied outside GitHub today? If not, do not commit it.

If sensitive material is ever committed, assume public exposure. Rotate affected secrets immediately and remediate repository history where useful, while recognizing that prior public copies may persist elsewhere.
